# 🚔 Crime Incident Intelligence Dashboard 2025

## 📊 Dashboard Preview
![Dashboard](dashboard.png)

## 📌 Project Overview
This project analyzes crime incidents in 2025 using Power BI.  
It focuses on identifying trends, patterns, and key insights from the dataset.

## 🔍 Key Insights
- Total incidents overview  
- Monthly crime trends  
- Day vs Evening vs Night analysis  
- Ward-wise and district-level insights  

## 🛠 Tools & Technologies
- Power BI  
- Excel  
- DAX  

## 📁 Files in Repository
- Crime_Incidents_in_2025_data.xlsx  
- Crime_Incidents_in_2025_Report.pbix  
- Project Documentation.docx  

## 🚀 How to Use
1. Download the .pbix file  
2. Open in Power BI Desktop  
3. Explore the interactive dashboard  

## 📌 Conclusion
This dashboard helps in understanding crime patterns and supports better decision-making.
